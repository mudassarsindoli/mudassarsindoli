## 🧰 Developer Tools & Templates

Tools that save developers time and give new projects a solid start.

| Project | Why it matters |
| --- | --- |
| [**scope-replace**](https://github.com/mudassarsindoli/scope-replace) | A VS Code extension for find-and-replace across *selected* files. It fixes the all-or-nothing nature of global search by letting you choose exactly which files change. |
