## Engineering Principles

**Failure is a first-class concern.**  
Design systems to recover, not just to succeed.

**Configuration over hard-coding.**  
Change behaviour without rewriting the engine.

**Automate repetitive work.**  
Use software to remove unnecessary manual effort.

**Boring technology, interesting problems.**  
Prefer proven technology when it solves the problem well.

**AI-generated code still needs proof.**  
Review it, test it, and verify its behaviour before shipping.
